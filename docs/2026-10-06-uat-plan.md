# Rencana UAT — MIVA Reel Studio v1

Prinsip: app baru dikirim ke Steven setelah **semua skenario otomatis di bawah lulus 100%** di Linux (cloud) dan Windows
(GitHub Actions), memakai footage asli `tes2.mp4`. Setelah itu Steven menjalankan checklist manual di laptopnya.
App disebut ready hanya kalau keduanya lulus. Setiap bug yang ditemukan = satu tes regresi baru sebelum diperbaiki.

## Alur editing end-to-end (diotomasi, Playwright untuk Electron)

| # | Langkah | Kriteria lulus |
|---|---|---|
| 1 | Buka app **tanpa internet** | Terbuka tanpa error; tidak ada request jaringan keluar (dicatat dan harus 0) |
| 2 | Import `tes2.mp4` lewat tombol dan lewat drag & drop file | Klip muncul di Media dengan durasi 00:37 dan thumbnail |
| 3 | Auto Edit | Transkrip muncul; potongan hening dan retake diusulkan; awal goyang ±2 dtk dibuang; ada progress dan Cancel |
| 4 | Review trim: coret kata, restore, keep/remove hening | Preview, transkrip, dan timeline berubah bersamaan; durasi final ter-update |
| 5 | Timeline: split (Ctrl+B), tarik tepi klip, ripple delete, snapping, magnet | Tidak ada celah hitam; sinkron audio-video tetap |
| 6 | Undo/redo untuk setiap aksi di 4–5 | Kembali persis ke keadaan sebelumnya |
| 7 | Subtitle: jadikan kata kunci, ganti animasi, hit boom | Boom maks 1; SFX ikut berubah otomatis |
| 8 | Drag SFX ke track SFX, drag gambar/video ke Overlay | Muncul di posisi drop; ikut terdengar/terlihat di preview |
| 9 | Transform + keyframe (scale/posisi/rotate/opacity) | Nilai antar keyframe ter-interpolasi di preview dan hasil export |
| 10 | Audio: volume, fade, noise reduction, voice enhance, ducking | Level akhir sesuai target (−14 LUFS ±1, puncak ≤ −1 dBFS) |
| 11 | Speed, adjust warna, grade preset, Remove BG, Stabilize | Diterapkan di preview dan export |
| 12 | Simpan versi (v1→v2), tutup paksa app, buka lagi | Autosave pulih; v1 dan v2 bisa dibuka; versi lama tidak tertimpa |
| 13 | Export 1080p / 2K / 4K × 30/60 fps × H.264/HEVC ke folder pilihan (Browse) | File ada di folder itu; resolusi dan fps sesuai; durasi = durasi final ±1 frame |
| 14 | Verifikasi hasil export | Tidak ada frame hitam; sinkron A/V; frame di detik kunci = snapshot preview (selisih piksel di bawah ambang); cover JPG dan salinan WA ada kalau dipilih |
| 15 | Cancel export di tengah | Tidak ada file setengah jadi tertinggal; app tetap responsif |
| 16 | Proyek dibuka oleh skill `/reel-edit` | `edit.json`/`captions.json`/`timing.json` terbaca tanpa error |

Tes unit dan regresi tambahan: logika potong (celah kata, padding), pemetaan waktu setelah speed, aturan SFX
(kepadatan, boom maks 1, riser jatuh di kata kunci pertama), kamera (tanpa tepi hitam), mix (LUFS, puncak).

## Yang tidak bisa dicakup tes otomatis (dicek Steven di laptop)

- GPU: Whisper CUDA, NVENC, Remove BG CUDA. Runner cloud dan GitHub Actions tidak punya GPU NVIDIA.
- Waktu nyata Auto Edit dan export di Ryzen 7 7735HS + RTX 4060. Target performa ditetapkan setelah pengukuran pertama.
- Rasa: pilihan SFX, timing subtitle, gaya kata kunci. Claude tidak bisa mendengar.
- Variasi footage lain (indoor, malam, landscape, HP lain).
- Peringatan SmartScreen saat install (tanpa code signing).
